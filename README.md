# BudPdf Converter

Клієнтський вебдодаток для швидкої підготовки PDF-документів під вимоги банків та митних органів. Працює повністю локально у браузері без завантаження файлів на зовнішні сервери.

🌐 **Live Demo:** [budpdf.vercel.app](https://budpdf.vercel.app/)

---

## ✨ Основні можливості

* **Посторінковий поділ:** Автоматичне розбиття багатосторінкових PDF-файлів (договорів, інвойсів) на окремі сторінки.
* **Гнучкі ліміти розміру:** Автоматичний підбір роздільної здатності (DPI) та стиснення під вибраний ліміт:
  * **До 490 КБ** — стандартний суворий ліміт для банківських систем.
  * **До 1.9 МБ** — збільшений ліміт для збереження максимальної деталізації.
* **Вибір колірної схеми:**
  * **Grayscale** — переведення у чорно-білий формат для зменшення ваги файлу.
  * **Кольоровий** — збереження оригінальних кольорів документа (печаток, підписів).
* **Попередній перегляд:** Швидкий перегляд кожної обробленої сторінки у модальному вікні перед завантаженням.
* **Пакетне завантаження:** Завантаження результатів поштучно або єдиним **ZIP-архівом**.
* **100% Конфіденційність:** Усі обчислення відбуваються локально на пристрої користувача.
* **Двомовність:** Підтримка української (UA) та англійської (EN) мов.

---

## 🛠 Технологічний стек

* **HTML5 / JavaScript (ES6+)** — ядро додатка (Single-File Architecture).
* **Tailwind CSS** — стилізація та адаптивний інтерфейс.
* **PDF.js** — рендеринг PDF-сторінок у браузері.
* **jsPDF** — генерація оптимізованих PDF-документів.
* **JSZip** — формування ZIP-архівів для масового завантаження.

## 🚀 Як користуватися

1. Перейдіть на сайт [budpdf.vercel.app](https://budpdf.vercel.app/).
2. Перетягніть один або декілька PDF-файлів у зону завантаження.
3. Оберіть потрібний **ліміт розміру** (490 КБ або 1.9 МБ) та **колірну схему**.
4. Натисніть **«Розділити та конвертувати»**.
5. Перегляньте готові сторінки за потреби та завантажте їх окремо або одним ZIP-архівом.
